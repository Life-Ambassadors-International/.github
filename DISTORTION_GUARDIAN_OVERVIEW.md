### T_D Index Computation

```python
def td_index(self, window: int = 50) -> float:
    """
    Compute distortion transmutation factor from recent events.

    Returns:
        float in [0.0, 1.0] where:
        - 1.0 = no distortion detected (pure field coherence)
        - 0.0 = constant hostile distortion (field under attack)
    """
    recent_events = self.event_log[-window:]
    if not recent_events:
        return 1.0  # No data = assume clean field

    # Map classifications to penalty weights
    penalty_map = {
        BENIGN_POLICY: 0.0,           # No penalty
        DISTORTION_SPAM: 0.2,         # Light penalty
        DISTORTION_POLICY_ABUSE: 0.5, # Moderate penalty
        DISTORTION_TROJAN: 1.0,       # Full penalty
    }

    penalties = [penalty_map[e.classification] for e in recent_events]
    avg_penalty = sum(penalties) / len(penalties)

    # Invert: high penalty → low T_D
    td = max(0.0, 1.0 - avg_penalty)
    return td
```

## 🔐 Security & Privacy Considerations

### What the Guardian Does NOT Do

❌ **Does NOT** phone home or send data to external servers
❌ **Does NOT** delete files (only quarantines)
❌ **Does NOT** modify system configuration without consent
❌ **Does NOT** persist across reboots unless explicitly configured
❌ **Does NOT** run with elevated privileges (operates in userspace)

### What the Guardian DOES Do

✅ **Does** keep all processing local (SIPL P7)
✅ **Does** require explicit consent for every scan (SIPL P1)
✅ **Does** preserve full file ownership (SIPL P2)
✅ **Does** log every decision transparently (SIPL P4)
✅ **Does** allow instant quarantine reversal (SIPL P3)
✅ **Does** return all telemetry value to the user (SIPL P6)
✅ **Does** respect voluntary operation (SIPL P5)

### Threat Model

The Guardian defends against:
1. **Silent policy injection** by unidentified processes
2. **Sovereignty extension blocking** by malware or corp policy
3. **Hidden configuration tampering** that users didn't authorize
4. **Supply chain compromise** via unsigned/untrusted artifacts

The Guardian does NOT defend against:
1. **Physical access attacks** (user must secure their device)
2. **Root/admin-level persistence** (Guardian runs in userspace)
3. **Network-level surveillance** (use Tor/VPN separately)
4. **Hardware backdoors** (requires physical security measures)
